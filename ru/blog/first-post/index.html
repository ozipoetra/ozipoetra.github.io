Почему Astro?

Astro — это современный фреймворк для создания быстрых статических сайтов. Благодаря архитектуре островов, Astro отправляет ноль JavaScript в браузер по умолчанию. Это означает, что ваш сайт будет быстрее и легче.

Основные особенности

  • Ноль JavaScript по умолчанию
  • Архитектура островов для интерактивности
  • Поддержка MDX для интерактивного контента
  • Встроенная поддержка интернационализации
  • Интеграция с популярными сервисами
