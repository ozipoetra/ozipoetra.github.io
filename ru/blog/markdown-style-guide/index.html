Цитаты

Элемент blockquote представляет контент, который цитируется из другого источника, при необходимости с указанием автора, которое должно находиться внутри элемента footer или cite, и при необходимости с внутристрочными изменениями, такими как примечания и сокращения.

Блоки кода

Синтаксис

мы можем использовать 3 обратных апострофа ``` на новой строке, написать фрагмент кода и закрыть его 3 обратными апострофами на новой строке. Чтобы подсветить синтаксис конкретного языка, напишите название языка после первых 3 обратных апострофов, например: html, javascript, css, markdown, typescript, txt, bash

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title>Example HTML5 Document</title>
  </head>
  <body>
    <p>Test</p>
  </body>
</html>
```

Результат

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title>Example HTML5 Document</title>
  </head>
  <body>
    <p>Test</p>
  </body>
</html>

Типы списков

Нумерованный список

Синтаксис

1. Первый пункт
2. Второй пункт
3. Третий пункт

Результат

  1. Первый пункт
  2. Второй пункт
  3. Третий пункт

Маркированный список

Синтаксис

- Пункт списка
- Еще один пункт
- И еще один пункт

Результат

  • Пункт списка

Другие элементы — abbr, sub, sup, kbd, mark

Синтаксис

<abbr title="Graphics Interchange Format">GIF</abbr> — это формат растровых изображений.

H<sub>2</sub>O

X<sup>n</sup> + Y<sup>n</sup> = Z<sup>n</sup>

Нажмите <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>Delete</kbd>, чтобы завершить сеанс.

Большинство <mark>саламандр</mark> ведут ночной образ жизни и охотятся на насекомых, червей и других мелких существ.
