## 💡 About This Repository

This repository hosts the source code and content for my personal blog, **ozipoetra.github.io**, powered entirely by **GitHub Pages**.

It serves as a digital notebook, documentation center, and portfolio, primarily focusing on:

* **💻 Tech & Code:** Deep dives into **[Specific Programming Language/Framework, e.g., JavaScript, React, Python]**.
* **🤖 AI/ML:** Exploring new models, tutorials, and ethical considerations in **Artificial Intelligence**.
* **🛠️ Tools & Productivity:** Reviews, guides, and tips on maximizing efficiency with various software.
* **🧘 Personal Reflections:** Thoughts on career, learning, and life outside of code.

---

## ⚙️ Technology Stack

This blog is built using a combination of simple yet powerful tools:

* **Platform:** **GitHub Pages** for seamless hosting and deployment.
* **Static Site Generator:** **Astro** *
* **Styling:** **[Tailwind]**
* **Deployment:** Automatic deployment is handled by GitHub Actions or the standard GitHub Pages build process.
